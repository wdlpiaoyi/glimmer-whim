# 正式内容（规划）

正式灵感内容尚未开始加入，本文件用于记录它的定位与规划。

## 是什么

正式内容指面向玩家的具体灵感，构建在引擎、交互、串联与渲染框架之上。

## 与开发测试内容的区别

| | 正式内容 | 开发测试内容 |
| --- | --- | --- |
| 位置 | `whims/` | `whims/dev/` |
| 注册 | 始终注册 | 由 `dev.enabled` 控制 |

## 每个正式灵感应记录

- id 与命名空间
- 锚与锚数据
- `{参数}`
- 角色（`ELEMENT` / `MODIFIER`）
- 修饰维度（`power` / `range`）
- 可接受的目标类型
- 生命周期
- 生成规则

## 生成

引擎会周期性把 `WhimSpawnContext` 交给每个已注册的 `WhimType`，由类型自身的 `spawn()` 决定是否生成。正式内容的生成规则写在这里。目前生成系统只有最小闭环与开发测试示例。
